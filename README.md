
#  Projeto simples de Cadastro de Usuário em Java

Este projeto implementa um sistema de **CRUD (Create, Read, Update, Delete)** para gerenciamento de usuários, utilizando **Java** como linguagem principal e o **H2 Database** como banco de dados relacional em memória.

## Funcionalidades
- **Cadastrar usuários** com informações básicas (nome, email, etc.)
- **Listar usuários** já cadastrados
- **Atualizar dados** de um usuário existente
- **Excluir usuários** do sistema
- Integração com **H2 Database**

## Tecnologias Utilizadas
- **Java** (JDK 17 ou superior recomendado)
- **H2 Database** (banco de dados em memória)
- **SpringBoot**

O projeto tem como objetivo o uso de **CRUD em Java**, mostrando como integrar aplicações com o **H2 Database** de forma simples , mas que seja eficiente. É ideal para estudos, e aprendizado de conceitos em java.
